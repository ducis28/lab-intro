\section{教員について}

専門分野は\emph{アルゴリズムと計算量の理論}，特に，\emph{離散データのマッチング}です。
ざっくりと説明すると，アルゴリズムとは問題の解き方であり，計算量はそのアルゴリズムの効率を表す尺度のひとつであり，離散データは単純な構造（文字列や木など）を持つデータから，複雑な構造（グラフ等）を持つデータを含むものを指します。

アルゴリズム研究の最大の目的は，計算機 (computer) の処理を速くすることです。そのための手段として，数学的な解析や計算機実験を実施します。

一方で，講義・研究・その他の用務上の必要からプログラムを書くことも多く，その関係から，\emph{情報システムの開発}にも大いに興味があります。最近はこちらに重点を置くことが多くなっています。利用するプログラミング言語は最近では Python と JavaScript が多く，他にも C/C++, Java, Ruby などを使います。

\section{リサーチ・プロジェクト（卒業研究）の進め方}

卒業研究は主に個人で行います。グループ研究に興味がある場合は早めに計画を立てて申し出てください。
方向性や進捗を確認できるよう，\emph{全体ミーティング（毎週）}と\emph{個別ミーティング（随時）}を活用してください。
人数が少ない年度は個別ミーティング中心，人数が多い年度は全体ミーティング中心となります。
たとえば2020年度は卒研生を3つのゼミ（アルゴリズム，機械学習，情報システム）に分割してゼミ単位でミーティングを行いました。
2021～2026年度は週2回の全体ミーティング中心です。
週4コマのゼミの中で勉強会（プログラミング，機械学習等）も実施しています。

研究室に配属が決まったら遠慮せずに研究室に来てください。
ゼミ・勉強会に参加することも可能です。
先輩の様子を見て話を聞いてみてください。卒業研究において必要なものは何か，考えてください。
見る・聞くだけでなく自分でやってみることも大切です。
\emph{積極性・主体性}を重視します。\emph{2年次生のうちから先輩の卒業研究を引き継ぎ，改善したものを学外で発表して受賞した先輩たち}もいます。ぜひチャレンジしてください。

\subsection*{面接について}

\begin{itemize}
\item 原則として場所は個人研究室（MK515），時間は15分から30分程度を予定しています。
\item 事前に電子メールでアポをとってください。
  \begin{itemize}
  \item 件名（Subject）には「面接希望」と学生ID・氏名を含めてください（例:「面接希望（1108240999文情次郎」）。
  \item 社会人として電子メールの基本的な使い方を勉強したうえで連絡をください（評価対象です）。
  \item 効率よくアポをとる方法を考えて実践してください（評価対象です）。
  \item 日時確定の後，提出物について指示をします。
  \end{itemize}
\item $\text{アポ25点} = \max\{0,(\text{電子メール送信時期による基礎点}) - (\text{メールでのアポの取り方による減点})\}$
  \begin{itemize}
  \item 「電子メール送信時期による基礎点」は，アポのための最初のメール送信時刻です（Dateヘッダフィールドを信じますが，メールヘッダReceived等から推測して偽装とみられる場合は不正として扱います）。
  同志社大学一斉休暇明け（8月17日まで）までは上限25点，以降は1日ごとに1点を減じ，9月11日(金)以降は0点となります。
  \item 「メールでのアポの取り方による減点」は，最大25点です。常識的なビジネスメールの範囲であれば減点しません。大学の電子メールアドレスを利用しているか，件名は適切か，本文の形式は適切か，アポのために必要な情報が過不足なく含まれているか，といった点を評価します。
  \end{itemize}
\item 準備10点
  \begin{itemize}
  \item アポ確定後の指示にしたがって，面接の準備をしてください。
  \item 提出物は，生成AIとの対話ログです。生成AIは何を使っても構いません。
  \item 面接の1時間前までに指定された提出窓口（Formsを予定）に提出をしてください。
  \end{itemize}
\item 質疑応答10点
  \begin{itemize}
  \item 主に(1)志望理由(2)提出物(3)基礎知識を確認するための質問を対面でおこないます。
  \end{itemize}
\end{itemize}
